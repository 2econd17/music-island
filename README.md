<h1 align="center">Music Island</h1>

<p align="center">
  «Динамический остров» как на iPhone — для Windows.<br>
  Поверх всех окон показывает, что сейчас играет: обложка, трек, исполнитель и живой визуализатор.
</p>

---

## Что умеет

- **Показывает текущий трек** из Яндекс Музыки (приложение и сайт в браузере), а также из Spotify, YouTube в браузере, VK Музыки и любого плеера, который Windows показывает в своём всплывающем окне громкости.
- **Визуализатор по настоящему звуку** — бары прыгают в такт музыке и красятся в цвет обложки.
- **Разворачивается при наведении**: большая обложка, прогресс трека, кнопки ⏮ ⏯ ⏭.
- **Прячется сам**, если музыка на паузе (время настраивается).
- **Глобальные горячие клавиши** — работают даже в игре или браузере.
- **Настраивается всё**: шрифт, размер, цвета, прозрачность, скругление, угол экрана, монитор, отступы.
- **Один .exe**, без установки. Автозапуск с Windows — одной галочкой.

## Установка (для всех)

1. Откройте страницу [Releases](../../releases) и скачайте **`MusicIsland.exe`**.
2. Положите его в любую постоянную папку, например `C:\Programs\MusicIsland\`.
3. Запустите. При первом запуске откроются настройки — выставьте, как нравится, и нажмите «Сохранить».
4. Вкладка **«Система» → «Запускать вместе с Windows»** — и всё.

> Windows SmartScreen может предупредить, что приложение неизвестно (у .exe нет платной цифровой подписи).
> Нажмите «Подробнее» → «Выполнить в любом случае».

Иконка приложения живёт в трее (возле часов, иногда под стрелкой `^`):
**левый клик** — настройки, **правый клик** — меню. Правый клик по самому острову открывает то же меню.

## Горячие клавиши по умолчанию

| Действие | Сочетание |
|---|---|
| Показать / скрыть остров | `Ctrl + Alt + M` |
| Пауза / воспроизведение | `Ctrl + Alt + P` |
| Следующий трек | `Ctrl + Alt + →` |
| Предыдущий трек | `Ctrl + Alt + ←` |
| Развернуть / свернуть остров | `Ctrl + Alt + E` |

Меняются в **Настройки → Горячие клавиши**. Если сочетание уже занято другой программой, приложение об этом скажет.

## Настройки

Всё меняется в окне настроек, изменения сразу видны на острове. Хранятся в
`%APPDATA%\MusicIsland\config.json` — этот файл можно править руками или перенести на другой компьютер.

| Вкладка | Что там |
|---|---|
| Внешний вид | шрифт, размер текста, цвет текста и фона, прозрачность фона и всего острова, обводка, цвет визуализатора (из обложки или свой), количество баров, показ обложки/исполнителя |
| Размер и место | масштаб, ширина и высота острова, скругление, угол экрана (в т.ч. сверху по центру — как настоящий Dynamic Island), монитор, отступы |
| Поведение | через сколько прятать на паузе, разворот при наведении, «клики сквозь остров», визуализатор и его чувствительность, показывать только Яндекс Музыку |
| Горячие клавиши | все сочетания |
| Система | автозапуск, папка настроек, сброс |

## Частые вопросы

**Остров не появляется.** Проверьте, что трек отображается во всплывающем окне громкости Windows (клавиши громкости на клавиатуре или иконка звука в трее). Если там его нет — Windows о нём не знает, и остров тоже. Ещё проверьте, не выключен ли остров (`Ctrl + Alt + M`).

**Показывает не тот плеер.** Включите «Показывать только Яндекс Музыку» во вкладке «Поведение». ID текущего плеера виден там же — его можно добавить в список приоритетных.

**Остров не виден в игре.** В режиме «Полный экран» (exclusive fullscreen) Windows не даёт рисовать поверх игры. Переключите игру в «Оконный без рамки» (borderless).

**Бары не прыгают / прыгают от любого звука.** Визуализатор слушает весь звук, идущий на устройство вывода по умолчанию (поэтому реагирует и на звуки других программ). Если он не работает, бары переключаются на мягкую анимацию. Чувствительность настраивается.

**Где лог?** `%APPDATA%\MusicIsland\log.txt`.

## Запуск из исходников

Нужен Windows 10/11 и [Python 3.10–3.13](https://www.python.org/downloads/).

```bat
git clone https://github.com/YOUR_GITHUB_NAME/music-island.git
cd music-island
start.bat
```

`start.bat` сам создаст виртуальное окружение и поставит зависимости. Вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m island            :: обычный запуск
python -m island --demo     :: фейковый трек — проверить внешний вид
python -m island --debug    :: подробный лог в консоль
```

### Собрать .exe

```bat
build.bat
```

Готовый файл — `dist\MusicIsland.exe`.

### Автоматические релизы

В репозитории настроен GitHub Actions (`.github/workflows/release.yml`): при пуше тега вида `v1.0.0`
он сам соберёт `MusicIsland.exe` на Windows и прикрепит его к релизу.

```bat
git tag v1.0.0
git push origin v1.0.0
```

## Как это работает

- **Трек** — из Windows System Media Transport Controls (`winrt`), того же источника, что использует системное окно громкости.
- **Визуализатор** — WASAPI loopback-захват (`PyAudioWPatch`) + БПФ по 24 логарифмическим полосам (`numpy`).
- **Окно** — `PySide6` (Qt): прозрачное, поверх всех окон, без фокуса, не видно в Alt+Tab и панели задач.
- **Горячие клавиши** — `RegisterHotKey` из WinAPI.

```
island/
  app.py        трей, запуск, связывание всего
  overlay.py    сам остров: отрисовка, анимация, мышь
  media.py      чтение текущего трека из Windows
  audio.py      захват звука и спектр
  hotkeys.py    глобальные горячие клавиши
  settings.py   окно настроек
  config.py     настройки и их сохранение
  autostart.py  автозапуск через реестр (HKCU\...\Run)
```
